Honey Serve player card prompts
Last updated: 2026-08-14

This file keeps the reusable prompts for the Honey Serve player cards.
The most successful current style is the personal 3D chibi / Nendoroid-style
badminton figure card, generated from:

1. A player profile photo
2. The matching base figure card for the player's gender and current tier

Tier rule:
- S: 1700+
- A: 1500+
- B: 1300+
- C: below 1300

Tier visual language:
- S: premium platinum / diamond / holographic finish
- A: gold finish
- B: silver finish
- C: bronze finish

Workday profile photo lookup rule:
- If the player already has a Honey Serve account username and it looks like a
  Workday id, search Workday by that account username first.
- If the user gives a specific Workday/search id with the person's name, search
  Workday by that id first.
- If there is no account username and no explicit id, search Workday by the
  person's name.

Personal figure card prompt
===========================

Use this prompt when making an individual player card from a profile photo.
Provide two reference images:

1. The player's profile photo
2. The correct base figure card, for example female-b-figure.jpg or male-s-figure.jpg

Prompt:

Create a polished Honey Serve badminton player card by transforming the person
in the profile photo into a collectible 3D chibi / Nendoroid-style badminton
figure on the provided base card.

Keep the base card's full composition, tier color, frame, background, lighting,
badminton court mood, outfit concept, racket, pose, scale, and vertical card
aspect ratio. The result should still clearly look like the same Honey Serve
base card, only personalized with this player's face.

Use the base card as the primary image. Treat the profile photo as a stylized
identity reference, not as a face to merge or paste. Start from the base card's
existing Nendoroid-style face and adjust only simplified toy-like features.
Use medium-low-plus likeness strength: a little more specific than a generic
chibi, but clearly less realistic than a direct portrait. Preserve only stylized
toy-figure cues such as hair part and volume, forehead/face silhouette, eyebrow
thickness and angle, eye shape and spacing, nose/mouth impression, smile line,
jaw impression, and overall mood. Avoid copying exact facial proportions from
the photo. The result should feel like the base card figure was loosely
customized for this person, not like the real photo was inserted.

Keep the face clearly Nendoroid / collectible figurine style: simplified,
smooth, toy-like, softly rounded, stylized, with no realistic skin pores,
photo-realistic facial planes, narrow realistic eyes, natural human face
shading, or passport-photo look. Identity likeness should come from stylized
facial-design cues, not literal facial copying. Do not copy the source face
literally, do not preserve realistic skin texture, and do not paste or blend a
realistic human face onto the figure.

Make the person look attractive, polished, and slightly cooler than the source
photo while still recognizable. The expression should be calm, focused, and
confident, suitable for Korean badminton club members in their 30s. Avoid a
childish, overly cute, overly cheerful, teenage, or idol-like feeling.

The face should look like it was sculpted as part of the original Nendoroid-style
figure, with simplified stylized features, soft toy-like skin, and the same 3D
collectible finish as the base card. Keep the base card's head size, cheek
roundness, eye scale, and body proportions; do not make the face too big or too
realistic. Hair style may be adjusted if needed for the card style, but keep it
within the same toy-figure rendering.

For female players, keep the outfit sporty and practical. Prefer shorts or
athletic pants over skirts unless the base card explicitly needs otherwise.
For male players, keep the outfit sporty, clean, and competitive.

Do not add new text, logos, names, watermarks, captions, borders, UI elements,
or extra badges. Do not change the player's tier design. Do not crop the card.
Output one complete vertical player-card image.

Negative prompt / avoid:

- realistic pasted face
- realistic skin texture
- photo-like portrait face
- realistic human facial planes
- passport-photo face
- literal face copy
- oversized face
- distorted eyes
- baby face
- childish expression
- overly glamorous idol portrait
- heavy makeup
- wrong gender presentation
- changed card frame
- changed tier color
- extra text
- watermark
- blurry face
- duplicate rackets
- broken hands
- missing racket
- cropped body
- cropped card edges


Base figure card prompt
=======================

Use this prompt only when creating a new blank base card for a gender/tier.
No real profile photo is needed.

Prompt:

Create a vertical premium badminton trading card base image for a Honey Serve
club player. The card should feature a full-body collectible 3D chibi /
Nendoroid-style badminton figure in an energetic badminton pose, with a racket,
sporty outfit, and a clean premium card background.

Make the figure look like a high-quality collectible sports figurine: toy-like
3D surface, smooth skin, clean lighting, crisp details, polished product-card
rendering, and a badminton court atmosphere.

The character should feel like a Korean adult club badminton player in their
30s, not a child. Use a focused and confident expression. Keep the pose distinct
from the other tiers so S, A, B, and C cards do not look identical.

Use the tier finish:
- S: platinum / diamond / holographic premium finish, most elite and dramatic
- A: gold premium finish, strong and stylish
- B: silver finish, balanced and athletic
- C: bronze finish, simple but still polished

For female base cards, use sporty athletic shorts or pants, not a skirt. Keep
the body sporty but not overly muscular. For male base cards, use clean athletic
badminton styling.

Do not include any text, logos, names, watermarks, UI elements, or badges. Leave
space for the website overlay to add player information later. Output one
complete vertical card image.
